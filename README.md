# MILT AI

**My Intelligent Local Technology**: asistente personal de inteligencia artificial que funciona primero en local (Ollama), con modo web opcional y que se puede ampliar a escritorio (Tauri) y Android.

- [uv](https://docs.astral.sh/uv/) (gestiona Python 3.12 del proyecto)
